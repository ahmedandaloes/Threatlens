ThreatLens analysed 10 components and 10 data flows (8 crossing trust boundaries) of Dawaa Express and identified 33 threats: 4 Critical, 18 High, 11 Medium, 0 Low, covering 8 of the 10 OWASP Top 10 2021 categories. The highest risks are Forged webhook / callback from third party — Payment Gateway (Moyasar) → Backend API (risk 25/25); Internet-exposed admin panel without MFA — Admin Dashboard (risk 25/25); IDOR / Broken object-level authorization — Backend API (risk 25/25). Dawaa Express — pharmacy delivery app in Riyadh, Saudi Arabia. Customers order medicines through our Android and iOS mobile app (built with Flutter) and can upload a photo of their prescription. A Node.js backend API stores orders, customer names, phone numbers, delivery addresses and prescription images in PostgreSQL and an S3 bucket. Pharmacists review prescriptions in a web admin dashboard. Payments go through Moyasar (mada, Apple Pay, cards) and we send order updates and login OTP codes by SMS through Unifonic. Drivers are dispatched through a courier API. We are a team of 4 developers and host everything on AWS. We use Cloudflare in front of the API.

Details

Critical TL-001 Forged webhook / callback from third party — Payment Gateway (Moyasar) → Backend API (risk 25)

Backend API accepts callbacks from Payment Gateway (Moyasar) (Payment data). Without signature verification an attacker can forge 'payment successful' or status events.

STRIDE: Spoofing · Likelihood 5/5 × Impact 5/5

OWASP Top 10: A08:2021 Software and Data Integrity Failures
ASVS: V10.3 Application Integrity; V13.1 Generic Web Service Security
CWE: CWE-345

Mitigation: Verify payment & partner webhook signatures.

Basis: F08: https auth=none third_party->dmz

Critical TL-002 Internet-exposed admin panel without MFA — Admin Dashboard (risk 25)

Admin Dashboard is reachable from the internet and protected only by password. Staff accounts are the highest-value phishing target.

STRIDE: Spoofing · Likelihood 5/5 × Impact 5/5

OWASP Top 10: A07:2021 Identification and Authentication Failures
ASVS: V4.3 Other Access Control Considerations; V2.8 One Time Verifier
CWE: CWE-308, CWE-306

Mitigation: Enforce MFA for privileged and staff accounts. Restrict admin panel to VPN / IP allow-list.

Basis: type=admin_panel, zone=dmz, auth=password, controls=none documented

Critical TL-003 IDOR / Broken object-level authorization — Backend API (risk 25)

Backend API exposes records by ID (Health data (PHI), Payment data, Personal data (PII), Credentials / tokens). If ownership is not checked server-side, changing an ID returns another customer's data.

STRIDE: Information Disclosure · Likelihood 5/5 × Impact 5/5

OWASP Top 10: A01:2021 Broken Access Control
ASVS: V4.2 Operation Level Access Control
CWE: CWE-639, CWE-862

Mitigation: Object-level authorization on every record access (anti-IDOR/BOLA).

Basis: type=api, zone=dmz, auth=jwt, controls=none documented

Critical TL-004 Payment amount / order tampering — Backend API (risk 20)

Backend API handles payments. If totals, discounts or amounts are accepted from the client, attackers can pay less than the real price.

STRIDE: Tampering · Likelihood 4/5 × Impact 5/5

CWE: CWE-602, CWE-840
