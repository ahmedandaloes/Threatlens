Threat Model — Nile Threads E-commerce Store

ThreatLens v1.0.0 · 2026-10-08 20:22 · mode: offline · STRIDE + OWASP Top 10 2021 / ASVS 4.0.3 / CWE

1. Executive summary

ThreatLens analysed 13 components and 14 data flows (12 crossing trust boundaries) of Nile Threads E-commerce Store and identified 43 threats: 10 Critical, 22 High, 11 Medium, 0 Low, covering 10 of the 10 OWASP Top 10 2021 categories. The highest risks are API operations without any security requirement (3 endpoints) (risk 25/25); Unsigned webhook / callback endpoints (2 endpoints) (risk 25/25); Forged webhook / callback from third party — Paymob (cards & wallets) → Shop API (risk 25/25). Doing the 18 'Now' actions (~29.5 developer-days) removes the most risk per day of effort; the full plan is ~43.0 developer-days.

Critical TL-001 API operations without any security requirement (3 endpoints) (risk 25)

The OpenAPI spec declares no authentication on: `GET /orders/{orderId}/invoice`, `POST /payments/fawry/notify`, `GET /admin/export/customers`.

STRIDE: Spoofing · Likelihood 5/5 × Impact 5/5

OWASP Top 10: A07:2021 Identification and Authentication Failures
ASVS: V13.1 Generic Web Service Security; V4.1 General Access Control Design
CWE: CWE-306

Mitigation: Role-based access control on every privileged function.

Basis: OpenAPI: 3 matching operations

Critical TL-002 Unsigned webhook / callback endpoints (2 endpoints) (risk 25)

Callback operations without a declared security scheme must verify HMAC signatures: `POST /payments/paymob/callback`, `POST /payments/fawry/notify`.

STRIDE: Spoofing · Likelihood 5/5 × Impact 5/5

OWASP Top 10: A08:2021 Software and Data Integrity Failures
ASVS: V10.3 Application Integrity
CWE: CWE-345

Mitigation: Verify payment & partner webhook signatures.

Basis: OpenAPI: 2 matching operations
