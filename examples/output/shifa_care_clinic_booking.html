1. Executive summary

ThreatLens analysed 11 components and 12 data flows (10 crossing trust boundaries) of Shifa Care Clinic Booking and identified 43 threats: 4 Critical, 25 High, 14 Medium, 0 Low, covering 9 of the 10 OWASP Top 10 2021 categories. The highest risks are Forged webhook / callback from third party — Paymob Payment Gateway → Booking API (risk 25/25); Internet-exposed admin panel without MFA — Clinic Admin Dashboard (risk 25/25); IDOR / Broken object-level authorization — Booking API (risk 25/25). Doing the 18 'Now' actions (~28.5 developer-days) removes the most risk per day of effort; the full plan is ~54.0 developer-days.

Details

Critical TL-001 Forged webhook / callback from third party — Paymob Payment Gateway → Booking API (risk 25)

Booking API accepts callbacks from Paymob Payment Gateway (Payment data). Without signature verification an attacker can forge 'payment successful' or status events.

STRIDE: Spoofing · Likelihood 5/5 × Impact 5/5

OWASP Top 10: A08:2021 Software and Data Integrity Failures
ASVS: V10.3 Application Integrity; V13.1 Generic Web Service Security
CWE: CWE-345

Mitigation: Verify payment & partner webhook signatures.

Basis: F11: https auth=none third_party->dmz

Critical TL-002 Internet-exposed admin panel without MFA — Clinic Admin Dashboard (risk 25)

Clinic Admin Dashboard is reachable from the internet and protected only by session. Staff accounts are the highest-value phishing target.

STRIDE: Spoofing · Likelihood 5/5 × Impact 5/5

OWASP Top 10: A07:2021 Identification and Authentication Failures
ASVS: V4.3 Other Access Control Considerations; V2.8 One Time Verifier
CWE: CWE-308, CWE-306

Mitigation: Enforce MFA for privileged and staff accounts. Restrict admin panel to VPN / IP allow-list.

Basis: type=admin_panel, zone=dmz, auth=session, controls=['tls', 'csrf']

Critical TL-003 IDOR / Broken object-level authorization — Booking API (risk 25)

Booking API exposes records by ID (Personal data (PII), Health data (PHI), National ID / Iqama, Payment data, Credentials / tokens). If ownership is not checked server-side, changing an ID returns another customer's data.

STRIDE: Information Disclosure · Likelihood 5/5 × Impact 5/5

OWASP Top 10: A01:2021 Broken Access Control
ASVS: V4.2 Operation Level Access Control
CWE: CWE-639, CWE-862

Mitigation: Object-level authorization on every record access (anti-IDOR/BOLA).

Basis: type=api, zone=dmz, auth=jwt, controls=['tls', 'logging', 'orm']

Critical TL-004 Payment amount / order tampering — Booking API (risk 20)

Booking API handles payments. If totals, discounts or amounts are accepted from the client, attackers can pay less than the real price.

STRIDE: Tampering · Likelihood 4/5 × Impact 5/5

OWASP Top 10: A04:2021 Insecure Design
ASVS: V11.1 Business Logic Security
CWE: CWE-602, CWE-840

Mitigation: Recompute amounts and prices server-side.

Basis: type=api, zone=dmz, auth=jwt, controls=['tls', 'logging', 'orm']
