Threat Model — Masar HR & Payroll Portal

ThreatLens v1.0.0 · 2026-10-08 20:22 · mode: offline · STRIDE + OWASP Top 10 2021 / ASVS 4.0.3 / CWE

1. Executive summary

ThreatLens analysed 13 components and 13 data flows (11 crossing trust boundaries) of Masar HR & Payroll Portal and identified 25 threats: 1 Critical, 15 High, 9 Medium, 0 Low, covering 8 of the 10 OWASP Top 10 2021 categories. The highest risks are IDOR / Broken object-level authorization — HR Core API (risk 25/25); Weak session / token lifecycle — HR Core API (risk 16/25); Account takeover via single-factor authentication — HR Core API (risk 16/25). Doing the 11 'Now' actions (~19.0 developer-days) removes the most risk per day of effort; the full plan is ~34.5 developer-days.

Details

Critical TL-001 IDOR / Broken object-level authorization — HR Core API (risk 25)

HR Core API exposes records by ID (Personal data (PII), National ID / Iqama, Financial data, Credentials / tokens). If ownership is not checked server-side, changing an ID returns another customer's data.

STRIDE: Information Disclosure · Likelihood 5/5 × Impact 5/5

OWASP Top 10: A01:2021 Broken Access Control
ASVS: V4.2 Operation Level Access Control
CWE: CWE-639, CWE-862

Mitigation: Object-level authorization on every record access (anti-IDOR/BOLA).

Basis: type=api, zone=dmz, auth=jwt, controls=['tls', 'rbac', 'input_validation', 'audit_logging', 'logging']

High TL-002 Weak session / token lifecycle — HR Core API (risk 16)

HR Core API uses jwt tokens; without expiry, rotation and server-side revocation a stolen token stays valid indefinitely.

STRIDE: Spoofing · Likelihood 4/5 × Impact 4/5

OWASP Top 10: A07:2021 Identification and Authentication Failures
ASVS: V3.3 Session Termination; V3.5 Token-based Session Management
CWE: CWE-613

Mitigation: Harden session & token lifecycle.

Basis: type=api, zone=dmz, auth=jwt, controls=['tls', 'rbac', 'input_validation', 'audit_logging', 'logging']

High TL-003 Account takeover via single-factor authentication — HR Core API (risk 16)

HR Core API authenticates users with jwt only. Phished, reused or leaked passwords give an attacker full access to Personal data (PII), National ID / Iqama, Financial data, Credentials / tokens.

STRIDE: Spoofing · Likelihood 4/5 × Impact 4/5

OWASP Top 10: A07:2021 Identification and Authentication Failures
ASVS: V2.1 Password Security; V2.8 One Time Verifier
CWE: CWE-308, CWE-287

Mitigation: Enforce MFA for privileged and staff accounts.

Basis: type=api, zone=dmz, auth=jwt, controls=['tls', 'rbac', 'input_validation', 'audit_logging', 'logging']

High TL-004 Account takeover via single-factor authentication — Employee Self-Service Portal (risk 16)

Employee Self-Service Portal authenticates users with session only. Phished, reused or leaked passwords give an attacker full access to Personal data (PII), Financial data, Credentials / tokens.
